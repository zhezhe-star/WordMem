# Issue #22 真机验收清单

模拟器不支持 Apple Translation API，以下项目必须在物理 iPhone 上执行。
建议使用 iPhone 17 Pro / iOS 27.x，并记录设备型号、系统版本、Apple Intelligence 状态。

## 1. 首次导入（最关键）

1. 删除 App 或使用从未导入过的设备，确认英文→简体中文语言资源未安装。
2. 文字导入：输入一段英文，收起键盘。
3. 预期：系统弹出语言资源下载确认；同意后文档翻译和所有拆解词释义都出现。
4. 不允许出现：需要用户先看到“翻译暂时不可用”再手动重试才恢复。
5. 若系统仍提示语言不可用：确认弹窗文案引导到「设置 > App > 翻译 > 语言」下载「英语 → 简体中文」。

记录：是否出现系统下载弹窗、下载耗时、文档/释义是否都成功、是否出现失败弹窗。

## 2. 二次导入与冷启动

1. 杀掉 App 后重新启动，立即做一次文字导入。
2. 预期：无需手动重试，文档翻译与 chip 释义一次成功。

## 3. Apple Intelligence 不可用时的降级

1. 关闭 Apple Intelligence（或使用不支持高保真翻译的设备）。
2. 文字导入。
3. 预期：自动降级到 `.lowLatency`，文档和 chip 都翻译；不应直接弹失败弹窗。

## 4. 文档翻译失败

1. 构造可重试的失败（例如临时关闭 Apple Intelligence 同时清除语言资源，或使用测试开关）。
2. 预期：只弹一次“翻译暂时不可用”，按钮为“重试 / 取消导入”。
3. 点“重试”：文档与所有缺失 chip 一次性重试；已成功的释义不丢。
4. 点“取消导入”：回到文字编辑器，保留输入草稿；不写词书。

## 5. 仅单词释义失败

1. 让文档翻译成功、chip 翻译失败（可用测试开关或网络/资源限制构造）。
2. 预期：弹“部分单词释义暂不可用”，按钮为“重试 / 取消导入”。
3. 点“重试”：只补缺失释义，不重新翻译已完成文档。
4. 点“取消导入”：回到编辑器，保留草稿。

## 6. 图片导入取消路径

1. 选择图片并完成 OCR。
2. 触发翻译失败弹窗，点“取消导入”。
3. 预期：回到“已选图片 + 已识别原文”预览；图片仍在，可用“更换照片/重拍”重新选择；不关闭导入 sheet。

## 7. Share Extension

1. 从 Safari/任意 App 分享英文文本到 WordMem。
2. 构造翻译失败。
3. 预期：弹窗“翻译暂时不可用”，按钮“重试 / 取消”；取消关闭扩展并回到分享面板。

## 8. Translation Provider

1. 在系统翻译界面选择 WordMem。
2. 构造整句翻译失败：弹“翻译暂时不可用”，按钮“重试 / 退出”；退出关闭组件。
3. 构造拆解词翻译失败：弹“部分单词释义暂不可用”，按钮“重试 / 退出”；重试补齐释义。

## 9. 不得出现

- 任何模块内（翻译卡、chip 区、Share 卡片、Provider 卡片）的独立重试按钮。
- “暂不翻译后继续保存”旁路。
- 重试后文档有中文、拆解词仍无中文。
- 同一次失败连续弹多个弹窗。
